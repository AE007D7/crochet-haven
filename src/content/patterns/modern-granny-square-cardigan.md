A modern granny-square cardigan combines a familiar motif with deliberate fit, palette and finishing. Start with a sized cardigan layout; this guide helps keep the squares, seams and bands working together rather than turning a stack of motifs into an unplanned garment.

## Set the Color Rules

Choose a background color and a limited set of accent colors. Decide whether every square ends with the same round. A consistent outer round makes joins less visually busy, while alternating backgrounds creates a stronger patchwork effect. Lay several finished squares together before making the whole set.

## Block Before Counting the Layout

Measure a washed square and compare it with the pattern's motif gauge. Multiply by the planned number of squares, then account for the join method. Raised joins add thickness and can change the finished dimensions. Make a joined two-square sample if the seam is unfamiliar.

## Place the Shoulder and Sleeve Squares

Lay out front, back and sleeves separately. Mark neckline gaps and the intended underarm joins. Keep square orientation consistent, and label the panels so color placement survives assembly. Follow the pattern for partial motifs and shaping rather than adding a full square where it changes the neckline.

## Refine the Borders

After joining, try the cardigan on before adding cuffs and front bands. Pick up stitches evenly and check each band flat. Match button spacing to the finished front length, then reinforce the attachment points. Weave ends securely through the appropriate color areas.
